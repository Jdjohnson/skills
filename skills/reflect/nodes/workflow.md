# Reflection Workflow

Stay grounded, plain, and specific.

## Intake

1. Resolve the date, range, theme, or individual entry.
2. Confirm the exact source boundary from [source handling](sources.md).
3. Read enough raw material to support the reflection without summarizing every private detail.

## Analysis lens

Look for:

- repeated phrases, worries, wants, or avoided decisions;
- changes in energy, attention, confidence, or emotional tone;
- commitments and values that recur;
- tensions between stated goals and repeated behavior;
- counterexamples that weaken an apparent pattern;
- the next honest question, not a forced answer.

Avoid diagnosis, therapy-speak, generic self-improvement advice, task triage, and unsupported certainty.

## Response shape

Start with the point, then use the smallest useful shape:

1. **What I notice:** the main pattern or tension.
2. **Evidence:** short source-grounded signals, with paths when useful.
3. **What it might mean:** a careful interpretation, labeled as interpretation.
4. **One question:** the next useful question.
5. **Tiny next move:** optional and only when the writing clearly points to one.

For longer ranges, add **Pattern over time**, **What changed**, and **What keeps returning** only when supported.

The goal is not to manufacture insight. Make the useful signal easier to see.
