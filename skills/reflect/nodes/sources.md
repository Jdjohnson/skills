# Source Handling

Use only journal entries or similar personal writing the user supplied, pointed to, or configured for this workspace.

## Resolve the source

Use this order:

1. Text or files supplied in the current request.
2. Exact paths named by the user.
3. A journal route explicitly documented by workspace instructions.
4. A source used in an earlier reflection only when the user clearly asks to continue that reflection.

If none applies, ask the user to supply the entries or point to their location.

## Search carefully

For a date or range, restrict reads to matching entries. For a theme, search only inside the identified journal source, then read surrounding passages before interpreting a match.

Do not treat search hits alone as evidence of a pattern. Check context, recurrence, time span, and counterexamples.

## Source priority

Prefer raw first-person writing over generated summaries. Use plans, calendars, messages, activity logs, and automated context only when the user included them or they are part of the configured reflection source. Label those as context rather than journal evidence.

## Privacy

- Quote sparingly.
- Do not expose private details that are unnecessary to the requested reflection.
- Do not move source material into another file or system without approval.
- Never search broadly across a home directory or external account to discover journal material.
