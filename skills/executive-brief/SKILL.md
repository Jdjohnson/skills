# Executive Brief

Help the reader understand the issue quickly and well enough to act.

- Use supplied sources first. Research only missing or current facts that could change the brief, and cite authoritative sources.
- Synthesize multiple sources instead of summarizing them separately.
- Separate sourced facts from inference or recommendation. State material uncertainty and gaps plainly.
- Match precision and confidence to the evidence.

Use this shape unless the user requests another:

1. **Bottom line** — the main takeaway in two or three sentences.
2. **Key judgments** — three to five decision-relevant points; add confidence labels only when useful.
3. **Decision** — what must be decided, by whom, and the next useful action. If no decision exists, state what matters.
4. **Gaps** — missing, weakly sourced, or time-sensitive information that could change the conclusion.

Keep supporting detail behind the main answer. Keep the brief in the conversation unless the user asks or approves saving it, then follow the active environment's destination rules.
