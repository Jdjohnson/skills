# Item Review

Handle one item at a time. Base the five fields only on the local capture and known workspace context.

Choose one concise suggestion, such as:

- create a small briefing in the configured durable route;
- ask the user for missing intent or context;
- hand off the item to a separate bounded work session.

Map the user's response to a terminal local outcome: briefing, needs-context, handoff, quiet-file, defer, drop, or draft. Deferral needs both a reason and review date. Outbound action still requires separate approval after the exact draft or mutation is visible.

A handoff authorizes preparation of the work packet, not execution or consequential external action.
