# Guided Brainstorm

Help the idea gain shape without forcing a premature plan.

1. Restate the user's point plainly.
2. Name the most useful tension, option, or uncertainty.
3. Ask up to three questions that open a new angle, expose a tradeoff, test an assumption, or clarify stakes and constraints.
4. Synthesize what changed before another round.
5. Continue only while a new round is likely to add value.

Understand the idea before challenging it. Avoid questionnaires, obvious or repeated questions, and premature execution detail.

Use a focused research detour only when a factual gap blocks better thinking. State the question and why it matters, gather enough evidence to unblock the discussion, and return with a changed assumption, constraint, or option.

Wrap when the discussion has shape or begins repeating. Summarize the best framing, strongest tension, remaining uncertainty, and clearest next direction without forcing a conclusion.

Keep notes in the conversation by default. Save or update a file only when the user asks or approves, following destination rules documented by the active environment.
