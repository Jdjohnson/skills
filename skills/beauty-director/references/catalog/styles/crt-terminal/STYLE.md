# CRT Terminal

## Defining grammar

CRT Terminal treats text output as the whole visual field. The essential image is a strict character grid on a near-black screen, usually green or amber phosphor, with a visible prompt, cursor, dense command output, and modest optical glow. The character cells, limited line width, and repeated baseline create its structure. A beige keyboard or old monitor can provide context, but hardware without an active text interface is not enough.

The strongest references evoke a working terminal rather than a cinematic hacking cliché. Show plausible commands, logs, tables, diagnostics, or system responses arranged as continuous operational text. The screen may curve slightly and lose sharpness toward its edges. Scan texture, bloom, and persistence are supporting behaviors; they should never obscure the readable grid.

## Composition and type

Compose from the upper-left origin, like a real terminal session. Use line breaks, indentation, columns, repeated delimiters, and status blocks to create rhythm. One active cursor or reversed field can become the focal point. Keep margins narrow and make density purposeful: a sparse welcome prompt feels different from an active diagnostic stream, so choose the state that serves the brief.

Use a monospace bitmap or low-resolution terminal face with distinguishable zero, O, one, lowercase L, braces, and punctuation. Letter spacing must remain fixed. Hierarchy comes from position, uppercase, inversion, brightness, or a second phosphor value, not multiple type families. Avoid oversized movie-title typography floating over code.

## Color, material, imagery, and light

Start with black or deep charcoal, then one phosphor hue and two brightness steps. Amber can feel warmer and administrative; green often reads as technical and familiar. Add neutral casing, dust, or keyboard color only when the physical terminal appears. The screen supplies most of the light, gently illuminating nearby keys or an operator's hands.

Imagery should be absent or reduced to character-cell diagrams. A pixel logo, box-drawing table, progress bar, or schematic made from text remains native. Full-color photographs, decorative gradients, and glossy cards break the single-stream discipline. Optical effects should suggest glass and phosphor, not contemporary neon tubes.

## Common exits

The style fails when a dark laptop displays ordinary modern code, when green typography becomes a wallpaper pattern, or when rain-like symbols imitate a film franchise. It also fails when circuit boards or disassembled electronics replace the live command surface. Too many interface panels move the result toward Operational Dashboard; multicolor tearing moves it toward Glitch Art; sprites and tile maps move it toward 8-Bit Pixel Art.

## Medium adaptation

For websites and apps, preserve keyboard-first interaction, monospace alignment, visible focus, and accessible contrast. Use a responsive character measure instead of shrinking the grid until it blurs. In motion, animate cursor blink, line printing, scroll, and brief phosphor decay at restrained speeds. For presentations, place one convincing terminal frame on each slide and use conventional readable notes outside it. Print can reproduce the screen as a bounded dark field with spot green or amber ink, but body copy should not imitate a terminal for long passages. Brand systems can borrow prompts, brackets, and status syntax while keeping the primary mark usable without glow. Environmental and product applications work best when the display is active and task-specific rather than treated as anonymous retro hardware.
