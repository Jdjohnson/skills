# Flat Design UI

## Defining grammar

Flat Design UI is a screen-native system built from clear hierarchy, simple shapes, flat color, and reusable components. Use it when a product should feel approachable and efficient without simulated leather, glass, chrome, or physical controls. The direction is not merely “minimal.” It keeps enough visual distinction to make navigation, action, state, and content obvious while stripping away material imitation that does not help the task.

## Composition and type

Organize screens with a predictable layout grid and a small set of component patterns. Navigation, content, controls, and status should be distinguishable at a glance. Use spacing and color blocks before borders; reserve cards for real grouping rather than wrapping every item. Icons should share stroke, corner, proportion, and optical-size rules. Typography needs a compact hierarchy with legible body sizes, decisive labels, and restrained weight changes. Keep alignment consistent across screens, and use rounding only as part of a defined component system.

## Color, material, imagery, and light

Choose a limited palette with accessible contrast and explicit semantic roles for action, success, caution, error, and neutral surfaces. Flat does not mean lifeless: a strong accent, illustration, or data color can carry personality. Avoid gradients used as decoration, glass blur, bevels, and heavy shadows. If elevation is necessary, use overlap or one shallow shadow level to clarify interaction. Photography should sit in clean containers and support content, while illustrations should use the same geometric and color logic as the icons. Lighting belongs inside imagery, not on the interface chrome.

## Common exits

The style exits into Glassmorphism when translucent panels and background blur become structural. It becomes Corporate Modernism when the cross-media identity system matters more than product interaction, and Operational Dashboard when dense monitoring panels replace a general component language. Common failures include ambiguous icon-only controls, excessive empty space, low-contrast pastels, interchangeable rounded cards, and a decorative illustration style that obscures state. A flat screen still needs affordance and priority.

## Medium adaptation

For mobile products, protect thumb reach, clear navigation, and compact responsive components. For desktop tools, increase information density without multiplying visual treatments. For websites, use the same tokens for color, type, spacing, icons, and buttons across content and transactional states. In presentations or brand guidelines, show component families and state changes rather than isolated hero screens. Motion should explain continuity, selection, and hierarchy through short direct transitions. The design remains flat when animation supports comprehension without introducing a simulated physical world.
