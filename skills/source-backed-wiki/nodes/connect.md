# Connect

Connect two pages only when one changes, explains, contrasts with, or provides evidence for the other. Shared broad subject matter is insufficient.

1. State the proposed relationship in one sentence.
2. Inspect both pages and resolve their cited sources to verify the relationship beyond wiki prose.
3. If supported, add a reciprocal, labeled `## Related` entry to both pages. Mark a relationship as inference when sources support but do not state it directly.
4. Run both pages through one `connect` transaction using [ingest](ingest.md).

When a requested link is too weak, report the rejection and reason without editing.
