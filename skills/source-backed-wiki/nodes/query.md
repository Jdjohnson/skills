# Query

1. Read `wiki/index.md`, then only relevant pages.
2. If the index is insufficient, use the workspace's configured read-only search adapter. Check its freshness before depending on results and preserve canonical, derived, and runtime labels.
3. For consequential, current, disputed, or weak claims, resolve and read the page's cited source rather than trusting the summary alone.
4. Answer with supported synthesis, dates where they matter, tensions, and source links.

For capability or resource questions, group candidates by the requested outcome and distinguish observed use, assessment, trial, adoption, rejection, and unverified capture. Flag claims needing current verification before purchase or implementation.

Query is read-only by default. Only an explicit request to save the answer runs a `query-save` transaction through [ingest](ingest.md).
