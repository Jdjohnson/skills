# Light Morning

Use the same gather depth as `full` with less ceremony:

1. Present the shape of the day.
2. Ask one combined prompt for anything that changes the read.
3. Propose priorities, one central thing, and a compact work table.
4. Ask once for adjustments.
5. After alignment, preserve any raw words and update the configured day record without overwriting source material.

Offer the fuller conversation only when useful; do not repeat answered questions.
