# Recording Rules

## Raw words

- Preserve supplied journal text verbatim in the configured raw-source route.
- Never overwrite different raw material. Reuse identical content; otherwise create a distinct timestamped source unless the user explicitly requests an append.
- Do not expose more private journal detail than the current conversation needs.

## Synthesized records

- Keep raw journal text visibly separate from the assistant-authored plan or recap.
- Write planning content only after alignment; write closeout content only after the user approves the proposed capture.
- Preserve existing logs, completed rows, recaps, and file structure.
- Update the canonical period record for time-based truth. Update another routed record only when the task authorizes that write.
- Never treat a local status as evidence of an external mutation.
- Make historical corrections transparent and preserve lifecycle precision.

Put something in a parking lot only when the user defers it, a real future date removes it from the period, or it is waiting on a named dependency. Do not invent protective deferrals.
