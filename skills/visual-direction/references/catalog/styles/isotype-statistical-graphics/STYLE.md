# Isotype Statistical Graphics

## Defining grammar

Use this node when quantities should be understood through repeated standardized pictures. One pictogram represents a consistent unit; count, grouping, and comparison communicate the data. The method does not enlarge a symbol to show a larger number, and it is not a collection of decorative icons. Its power comes from transforming evidence into an ordered visual statement that can be scanned before it is read in detail.

## Composition and type

Begin with the quantitative relationship, then assign a stable unit and a pictogram simple enough to repeat cleanly. Align icons to rows or columns on a common baseline. Separate categories through spacing, restrained color, or clearly placed labels rather than stylistic variation. Partial units require a transparent convention and should be avoided when they create ambiguity. Typography stays concise and subordinate: short headings, category labels, values, and source notes. Use a neutral sans and keep labels aligned to the icon grid.

## Color, material, imagery, and light

Flat color and hard edges are essential. Start with one dark ink and a light ground, adding a small number of category colors only when they improve comparison. Pictograms should share silhouette logic, detail level, orientation, and visual weight. Photography, perspective, modeled volume, gradients, and expressive lighting work against the method because they make equal units look unequal. Printed output can carry slight ink texture, but the information must survive monochrome reproduction and small-scale viewing.

## Common exits

The style exits into Civic Wayfinding when an icon tells a person where to go rather than how much exists. It becomes Infographic Classic when arrows, timelines, charts, illustrations, and explanatory panels replace repeated unit symbols. It is not isometric drawing: perspective diagrams and three-dimensional blocks contradict equal visual units. Other failures include scaling one figure to imply magnitude, mixing unrelated icon styles, treating people as decorative patterns, or omitting the unit relationship entirely.

## Medium adaptation

For reports, use repeated symbols for a few consequential comparisons and accompany them with exact values and sourcing. For presentations, reveal groups in sequence while keeping the final count visible. For web pages, allow filtering or highlighting without changing unit scale. In motion, add or remove identical units rather than stretching them. For environmental displays, increase icon size and spacing while preserving the count logic. Always verify that the picture statement matches the underlying numbers and remains understandable without color alone.
