# Emoji Grammar

## Core grammar

Emoji Grammar uses interoperable pictograms as a compositional language. Meaning emerges through sequence, reaction, modifier, combination, and shared glyph behavior—not from a single enlarged face or object. Use it for playful instructions, reaction systems, community storytelling, campaigns, data annotation, and interfaces where compact symbols can form readable phrases.

## Composition and hierarchy

Set a baseline, token scale, spacing unit, and reading direction. Build a short sequence with a clear beginning, transformation, and response. Modifiers should attach visibly to a base token rather than float as decoration. Repetition can establish subject continuity, while arrows, punctuation, or panels may clarify temporal order. A grid is useful for inventory, but the hero needs syntax.

## Type and graphic language

Use labels only when the intended audience cannot infer the sequence or when accessibility requires a text equivalent. Maintain consistent outline, perspective, face construction, highlight, and palette across all symbols. Original glyphs should express the concept without reproducing a platform vendor’s exact image set. Treat vendor appearance as implementation-specific rather than universal.

## Color, material, imagery, and light

Bright yellow, blue, green, red, and neutral white can form an accessible core, with modifiers adding controlled variation. Keep rendering relatively flat and readable at inline scale. Shading, texture, and 3D depth must remain consistent across the family. Test tokens in color and monochrome, because meaning should not rely only on hue.

## Use across media

Interfaces need text alternatives, predictable ordering, and sufficient touch size. Editorial and social work can enlarge a sequence while preserving inline rhythm. Motion may reveal tokens one at a time or transform a base into its modified form. Physical applications should consider whether small details survive print, embroidery, enamel, or sticker production.

## Common exits

A lone icon demonstrates a glyph, not grammar. Random rows of cute symbols lack semantic connection. Brand-specific emoji copied from one platform create rights and interoperability problems. Dense pictogram charts become ISOTYPE-like information design, while independent kiss-cut motifs may belong to Sticker Sheet System.

## Direction recipe

Write a five-beat sentence in plain language, then replace each beat with an original token. Add one legitimate modifier or combined symbol, align every glyph to the same system, and test whether a new viewer can retell the sequence. Provide a concise text equivalent for accessibility.
